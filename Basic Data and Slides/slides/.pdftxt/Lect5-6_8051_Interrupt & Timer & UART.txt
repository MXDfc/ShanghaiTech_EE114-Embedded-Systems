    8051 interrupts (SFR)                                                                                                                     有疑问查
                                                                                                                                             datasheet
    • Related SFR                                                                      TCON Register
                                                                                       • TR0/1 为定时器T0/T1 的运行控制位
                                                                                         TR0 位由软件置位和复位。当GATE（TMOD 的D3 位）为0 时，
                                                                                         TR0 为1 时允许T0 计数；TR0 为0时禁止 T0计数。
                                                                                         当GATE为1时，仅当TR0等于 1且INT0（P3.2）输入为高电平时才
                                                                                         允许T0 计数。TR0 为0 或 INT0 输入低时都禁止T0 计数。
                                                                                       • TF0/1 为定时器T0/T1 的溢出标志位
                                                                                         当T0 被允许计数以后，T0 从初值开始加1 计数，最高位产生溢出时
                                                                                         置“1”TF0，并向CPU 请求中断，当CPU 响应时，由硬件清
                                                                                         “0”TF0；TF0 也可以由程序查询或清“0”。
                                                                                       • IE1/IE0 为外部中断请求标志
                                                                                       • IT1/IT0 为外部中断触发方式选择位；0=电平触发，1=边沿触发


                                                                                       IE Register
                                                                                       • EA: 中断允许总控制位（总使能）
                                                                                         EA=0, 禁止所有中断；EA=1, 开放所有中断。
                                                                                       • EX0(EX1): 外部INT0、INT1中断允许位
                                                                                       • EX0(EX1)=0, 禁止；EX0(EX1)＝1, 允许。
                                                                                       • ET0(ET1): 定时/计数器T0、T1中断允许位
                                                                                       • ET0(ET1)＝0, 禁止；ET0(ET1)＝1, 允许。
                                                                                       • ES: 串行中断允许位
                                                                                       • ES＝0，禁止； ES＝1，允许。

  8051 interrupts (Priority)                                                                                                                 有疑问查
                                                                                                                                            datasheet
  • Interrupt priorities                                                              IP Register
      – By default:                                                                   • PX0：外部中断0（INT0）优先级设定位
        Int0 > T0 > Int1 > T1 > Serial port                                           • PT0：定时中断0（T0）优先级设定位
      – Set the IP register to specify the priority                                   • PX1：外部中断1（INT1）优先级设定位
        levels                                                                        • PT1：定时中断1（T1）优先级设定位
                                                                                      • PS： 串行中断优先级；
                                                                                      • 0：低优先级；1：高优先级

                                                                                      ➢ 低优先级中断请求不能打断高优先级的中断服务；但
                                                                                        高优先级中断请求可以打断低优先级的中断服务，从
                                                                                        而实现中断嵌套。
                                                                                      ➢ 如果一个中断请求已被响应，则同级的其他中断响应
                                                                                        将被禁止。
                                                                                      ➢ 如果同级的多个请求同时出现，则按CPU查询次序确
                                                                                        定哪个中断请求被响应。其查询次序为：
                                                                                        外部中断0 > 定时中断0 > 外部中断1 > 定时中断１
                                                                                        > 串行中断。

  Timer Mode 1 C51 example                                       #include <reg52.h>
                                                                 #include <stdio.h>
                                                                 /*------------------ Timer 0 Interrupt Service Routine.
  • C51 program for a delay of 0.05 sec                          Set a breakpoint on 'overflow_count++'. ----------------*/
                                                                 static unsigned long overflow_count = 0;
    (50 000 machine cycles)                                      void timer0_ISR (void) interrupt 1
                                                                 {
                                                                     TR0 = 0;        /* Stop the Timer 0 */
                                                                     TH0 = 60;      /* Reload the initial value */
                                                                     TL0 = 176; /* Reload the initial value */
                                                                    overflow_count++; /* Increment the overflow count */
                                                                     TR0 = 1;       /* Restart the timer */
                                                                 }
                                                                 void main (void)
                                                                 { /*---------- Set Timer0 for 16-bit timer mode. The timer
                                                                 counts to 65535, overflows, and generates an interrupt. */
                                                                     TMOD = (TMOD & 0xF0) | 0x01; /* Set T0 Mode */
                                                                     TH0 = 60;            /* Load the initial value */
                                                                     TL0 = 176;           /* Load the initial value */
                                                                     ET0 = 1;             /* Enable Timer 0 Interrupts */
                                                                     TR0 = 1;             /* Start Timer 0 Running */
    1. Start the debugger.                                           EA = 1;              /* Global Interrupt Enable /

    2. Set a breakpoint on the overflow_count++ line in the ISR.
                                                                     Do Nothing. Actually, the timer 0
    3. Run the program.                                              interrupt will occur every 65536 clocks.
    Each time the interrupt routine is invoked, the debugger         --------------------------------------*/
    stops running the program. Position the cursor over the          while (1);
    overflow_count variable to view its current value.           }

  1. 串口、COM口是指的物理接口形式(硬件)。                                                            • 记住，这种接口的协议只有两种：

    in embedded systems.

      – SCLK: Serial Clock (output from master).
      – MOSI: Master Output Slave Input,
        (data output from master).
      – MISO: Master Input Slave Output,
         (data output from slave).
      – SS: Slave Select (often active low,

  1-Wire Sensor Interfacing
  • 1-Wire单总线是美国DALLAS公司推出的
    外围串行扩展总线技术，与SPI、I2C串行
    通信方式不同，它采用单根信号线，既传输
    时钟又传输数据，而且数据传输是双向的。
  • DS18B20 / DHT11 is a single wire digital
      humidity (20 to 90% RH) and temperature
      sensor(up to 50ºC), which provides humidity
      and temp. values serially.
  • 4 pins: 2 pins for supply, 1 not used and 1 for
    data (some model 3 pins)
  • The data pin is the only pin used for
    communication. Pulses of different TON and
    TOFF are decoded as logic 1 or logic 0 or
    start pulse or end of the frame.
